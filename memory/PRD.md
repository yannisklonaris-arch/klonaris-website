# Klonaris — PRD

## Original problem statement
Klonaris is an engineering-focused technical documentation service that transforms lengthy, messy, poorly arranged engineering documents into concise, structured, professional documentation with an engineering-minded human review of AI-assisted work. Premium dark navy / near-black brand identity, metallic silver accents, geometric typography, technical-line details, restrained futuristic motion. Bilingual FR/EN. Quote-based pricing only, GDPR privacy sections, legal pages, basic SEO, accessible responsive layouts, no fake testimonials/clients/prices/contact details/claims.

Modèle commercial (mis à jour 2026-09-14) : devis personnalisé → confirmation écrite par e-mail → paiement intégral (100 %) à la commande, avant le début du travail → traitement hybride (IA + revue humaine) → livraison. FIN du modèle acompte 50 % / solde 50 %.

## Architecture
- Frontend: Vite + React 19 + TS, Tailwind v4, motion (framer-motion) + lenis smooth scroll, React Context i18n (FR default / EN, persisted in localStorage), sonner toasts. Pages in `frontend/src/pages/`, dictionaries in `frontend/src/i18n/`.
- Backend: FastAPI `POST /api/quote-requests` : sauvegarde MongoDB `quote_requests` + Resend (notification propriétaire avec objet [URGENCE] en premier, confirmation bilingue FR/EN au visiteur). Sans RESEND_API_KEY valide : sauvegarde seule + confirmation affichée (`emailSent:false`). Honeypot anti-spam, case consentement IA obligatoire.
- Design: `/app/design_guidelines.json` — dark navy #070B14, metallic silver gradient text, blueprint grid, JetBrains Mono technical annotations, Manrope headings, DM Sans body.

## User personas
- Engineering/R&D lead with a messy technical document needing a professional deliverable.
- Founder handling everything personally (no team accounts, no dashboard).

## Core requirements (static)
Quote-based pricing only; bilingual FR/EN; confidentiality-first messaging; no invented credentials or claims; GDPR pages; accessible responsive layouts.
